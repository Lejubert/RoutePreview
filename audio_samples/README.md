# 🎵 Sample Background Music

This folder contains royalty-free background music for your Street View videos.

## 📥 Download Free Music

### Recommended Sources (All Royalty-Free & Free)

1. **YouTube Audio Library**
   - https://studio.youtube.com/channel/UC/music
   - Huge selection, completely free
   - Filter by mood, genre, duration

2. **Free Music Archive**
   - https://freemusicarchive.org/
   - Creative Commons licensed
   - Search for "travel" or "cinematic"

3. **Incompetech (Kevin MacLeod)**
   - https://incompetech.com/music/royalty-free/
   - Requires attribution
   - Great travel/background music

4. **Bensound**
   - https://www.bensound.com/
   - Free with attribution
   - High-quality tracks

5. **Pixabay Music**
   - https://pixabay.com/music/
   - No attribution required
   - Easy download

## 📋 How to Add Music

### Option 1: Use Sample Files (Coming Soon)
The app will include 2-3 pre-downloaded samples.

### Option 2: Download Your Own

1. Visit one of the sites above
2. Download an MP3 file
3. In the app, select "Upload Custom"
4. Choose your downloaded MP3

### Option 3: Add to audio_samples folder

1. Download MP3 files
2. Rename them:
   - `upbeat_travel.mp3`
   - `calm_journey.mp3`
   - `cinematic_epic.mp3`
3. Place in this folder
4. They'll appear in the app dropdown!

## 🎯 Tips for Choosing Music

1. **Match the mood**: Upbeat for cities, calm for scenic routes
2. **Length doesn't matter**: FFmpeg will loop or trim automatically
3. **Instrumental works best**: No distracting lyrics
4. **Medium tempo**: Not too fast, not too slow
5. **Test it**: Generate a short video first to preview

## 📝 Attribution Template

If using music that requires attribution, add this to your video description:

```
Music: [Track Name] by [Artist Name]
Source: [Website]
License: [License Type]
```

Example:
```
Music: Sunny by Bensound
Source: https://www.bensound.com
License: Creative Commons (Attribution Required)
```
